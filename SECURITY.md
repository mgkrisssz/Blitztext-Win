# Sicherheit / Security

Blitztext ist ein lokales Hobbyprojekt ohne Server. Trotzdem: Wenn du eine Sicherheitslücke findest
(z. B. Code-Ausführung über manipulierte Dateien, Probleme bei Autostart oder Update-Hinweis),
melde sie bitte **nicht öffentlich**, sondern über **Security → Report a vulnerability** in diesem Repository
(„Private vulnerability reporting“). Ich melde mich so bald wie möglich zurück.

If you find a vulnerability, please report it privately via *Security → Report a vulnerability* instead of opening a public issue.

Unterstützt wird jeweils die neueste Version.
